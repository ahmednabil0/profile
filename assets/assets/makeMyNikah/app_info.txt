app_breif:
MakeMyNikah is a premium, faith-centered matchmaking and matrimonial platform engineered to facilitate serious Islamic marriage proposals. The application provides a structured, privacy-conscious environment where users can create detailed profiles, specify religious and personal preferences, and connect with potential matches through a supervised, respectful communication framework. Built with a focus on community trust and data security, MakeMyNikah integrates comprehensive profile verification systems, advanced preference-based matching algorithms, and secure real-time chat infrastructure to bridge compatibility while honoring cultural and religious values.

technologies:
BLoC & Hydrated BLoC: Reactive state management providing persistent local state caching across app restarts for seamless user sessions.

Firebase Cloud Firestore & Realtime DB: Dual-tier database architecture leveraging Firestore for structured user profiles and match preferences, and Realtime DB for instant presence indicators and live chat message synchronization.

Firebase Cloud Functions: Serverless backend layer handling secure authentication token generation, push notification dispatching, and privacy-sensitive data processing off the client device.

Firebase Authentication & Multi-Factor Auth: Secure identity management pipeline supporting email/password-based registration alongside phone-based OTP verification flows.

Zego Cloud SDK: High-performance real-time communication engine used for secure voice and video calling features between matched users under consent-based session controls.

Firebase Cloud Messaging: Bulk push notification delivery infrastructure enabling real-time match alerts, message notifications, and proposal acceptance signals.

Stripe & In-App Purchase Integration: Secure payment processing architecture handling subscription-based premium tier unlocks, profile boosts, and advanced filtering feature purchases.

Sentry & Firebase Crashlytics: Enterprise-grade crash reporting and application performance monitoring (APM) suite ensuring robust runtime diagnostics.

Go Router: Declarative navigation controller enforcing deep-link capable routing and protected route guards for authenticated user shells.

Infinite Scroll Pagination: Lazy-loading optimization layer for efficient rendering of large user discovery feeds and matched profile histories.

Shimmer & Animated Loading Effects: Perceived-performance UI utilities rendering smooth skeleton screens during asynchronous data fetches and profile image decoding.
